# ZILOLEX Brand Assets

This directory contains the master logo files and branding guidelines.

## Official Brand Colors
- **Brand Green (Green House 4)**: `#245409` (RGB: 36, 84, 9)
- **Primary Black**: `#000000`
- **Dark Mode Emerald Accent**: `#34d399` / `#4ade80`
- **White**: `#ffffff`

## Files Included
- `Color logo - no background.svg`: Primary full-color logo for light backgrounds.
- `Color logo with background.svg`: Full-color logo on crisp white background (used for social media / OpenGraph).
- `White logo - no background.svg`: Inverted monochrome white logo for dark backgrounds.
- `Black logo - no background.svg`: Monochrome black logo for print and grayscale documents.
- `getting_started_guide.html`: Brand guide.

## Web Distribution
All web assets are published in `/public/brand/` and served statically.
